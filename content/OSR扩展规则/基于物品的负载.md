# 基于物品的负载

作者: Gavin Norman

*老派要典* 呈现了两种根据随身携带的装备和财宝数量来确定角色移动速率的方法。对于希望采用更抽象的，基于携带物品数量的方法的玩家，本文提出了第三种选择。

## 记录所携带的重要物品

玩家使用这种替代的负载系统时，不是记录携带物品的重量（以钱币为单位），而是记录携带的重要物品的数量。通用准则：可以单手携带的物品计为1件，需要双手携带的物品计为2件。非常沉重或体积庞大的物品，参照裁判的决定，可能算作 3 个或更多的物品。

### 已装备和包内的物品

每个携带的物品均被分类为已装备或在*包内*。

**装备物品**：角色正持有、主动使用或随时可以取用的任何物品，如穿戴的护甲、手持的盾牌或武器、入鞘的武器，以及腰带上佩戴的物品。

**包内的物品**: 所有其他打包进口袋、袋子、背包等的装备。作为可选项，在战斗中，取出打包好的物品花费一个回合。

> **角色卡**
>
> The Purist 角色卡，可在 necroticgnome.com 获取，包括一个基于物品的负载版本。

### 武器和盔甲

**武器**：单手武器算1件物品；双手武器算2件物品。

**弹药**：投射武器的负载中已经包括了弹药及其容器。

**盔甲**：盾牌算作1件物品；轻型盔甲（例如皮甲）算作1件物品；重型盔甲（例如链甲）算作2件物品。服装（即未着甲时）不计入负重。

### 冒险装备

标准冒险装备的物品重量列在了 *基于物品的冒险装备负载* 表中。

**成捆物品**：某些物品（例如火把、口粮）通常是成捆购买和携带的。至多3件此类物品（例如单个火把或数天的口粮）捆绑在一起计为1件物品。

**小型物品**：一些非常小的物品（例如项链、戒指）除非大量携带（依照裁判的判断），否则不会被视为负重。

**容器**：仅当不使用时，容器（例如背包、麻袋）才被视为一个物品。裁判必须判断一个容器可以存储多少物品。

### 宝藏

**钱币和宝石**：至多 100 枚钱币或宝石算作 1 件物品。

**珠宝**：小型物件（例如项链、戒指）不计入负重；较大物件计为1件物品。

**魔法物品**：法杖算作2件物品；其他算作1件物品。

## 移动速率

移动速率由携带的物品数量决定，详见 *基于物品的负载* 表。角色已装备和包内的物品数量都应在表内检索，并使用较慢的移动速率。

基于物品的负载

| 已装备物品 | 包内物品 | 移动速率 |
| ------------ | ------------ | ---------- |
| 0–3 | 0–10 | 120’ (40’) |
| 4–5 | 11–12 | 90’ (30’) |
| 6–7 | 13–14 | 60’ (20’) |
| 8–9 | 15–16 | 30’ (10’) |


**最大负载**：一个角色携带超过9件已装备物品或超过16件包内物品将无法移动。

## 坐骑与载具

坐骑或载具可以携带的物品数量通过将其钱币装载量（在《老派要典》中定义）除以100来计算。已装备物品和包内物品之间的区别不适用于坐骑和载具。

**示例**：一匹骑乘用马可以无负担地携带最多30件物品（3000金币），最多可以携带60件物品（6000金币）。

> **基于物品的负载示例**
>
> 摩根，一名战士，拥有以下装备：
>
> **6件已装备物品**：链甲（2件），盾牌（1件），剑（1件），短弓（2件，包括箭矢）。
>
> **4件打包的物品**：绳子（1件），火绒盒（1件），3份耐久口粮（捆，1件），水壶（1件）。
>
> **移动速率**：查看负载表，摩根装备了6件物品，对应移动速率为60'(20)，而她打包的4件物品对应120'(40)。她因此拥有60'(20)的移动速率，也就是这两个中较慢的一个。

> **力量调整值（可选规则）**
>
> 一个角色的近战力量调整值（参见《老派要典》中的属性值部分）可以应用于每种移动速率的包内物品数量区间。例如，一个力量为16（+2调整值）的角色可以在携带最多12件打包的物品保持120（40）的速率。

**成捆**： 列出了购买时，捆绑包中所有物品的重量（例如，7 份口粮 = 3 件）。

**容器**：仅在不使用时才算作物品。裁判必须判断一个容器可以存储多少物品。

**小型**：除非数量很大，否则不会成为负担。
