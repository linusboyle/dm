首先，欢迎参加我主持的游戏！请先阅读[[界域漫游指南：月狂的TTRPG团规\|团规]]，在跑团时自觉遵守跑团礼仪。

游戏采用**基础级/专家级龙与地下城规则**（B/X DnD），实际运作使用有中文代理的[[OSE/老派要典参团指南\|老派要典]]（OSE）代替。相比后世，这版DnD采用极度精简的规则，适合新手上手。玩家无需查阅冗长的规则书，在游戏过程中也基本无需关注复杂的规则问题。游戏的风格侧重于探索、RP和解谜，战斗一般非常危险，玩家应当避免卷入过多的冲突。

> [!NOTE]+ 关于DnD
> 虽然现今的DnD逐渐演变成了一个以战斗为主的跑团规则，最初的DnD其实很类似CoC（当然，从历史上来看是DnD在先）。DnD所开创的游戏风格代表着玩家在开放的奇幻沙盒式世界中自由探索和角色扮演，所作所为皆会影响世界的动态。叙事不依靠预定的情节，而是靠玩家在游戏中的行为逐渐构筑（涌现式叙事）。敌人往往非常致命，因此明智的冒险者应该学会避免战斗，而不是踢门硬干。
> 
> 不像3版之后的DnD，这个时候的冒险者只比普通人强一点（类似CoC调查员）。职业只有最经典的战法牧贼，没有厚重的规则书，也没有让人眼花缭乱的专长可以用来构筑。一切乐趣都来源于TRPG最初的魅力：做任何想做的事，以自己的选择铺就传奇。


## 快速车卡

创建人物时有任何问题可咨询DM

1. 投掷属性点，按照力量、智力、睿知、敏捷、体质和魅力的顺序，依次骰3d6（`.r6#3d6`）
	- 若是给角色投骰的属性值非常糟糕：譬如每项属性都只有 8 或以下，或是某项属性过低，可以向DM申请舍弃这个角色，然后重新开始。
2. 选择职业，从下列职业中选择一个。参考对应页面将5项豁免（D,W,P,B,S）以及职业特性填入人物卡。此外，1级人物的基础攻击加值为0
	1. [[OSE/职业/经典奇幻/牧师]]
	2. [[OSE/职业/经典奇幻/战士]]
	3. [[OSE/职业/经典奇幻/魔法师]]
	4. [[OSE/职业/经典奇幻/盗贼]]
3. 调整属性值：若是愿意，你可以通过降低其他（非主要）属性值来提升角色的主要属性。所选属性值每降低 2 点，主要属性就能增加 1 点。限制如下：
	1. 这种方法只能降低力量、智力和睿知。 
	2. 属性不能降低到 9 以下。
	3. 某些角色职业可能带有额外约束。
4. 标明属性调整值：现在角色的属性值已经固定下来了，在角色卡上标出任何关联的奖励或是惩罚（比如近战/投射加值）。每项属性的调整值见下表：

	| 属性值 | 调整值 |
	| ------ | ------ |
	| 3      | -3     |
	| 4-5    | -2     |
	| 6-9    | -1     |
	| 9-12   | 0      |
	| 13-15  | +1     |
	| 16-17  | +2     |
	| 18     | +3     | 

5. 骰生命：按照所选职业的对应骰子类型进行投骰来决定你角色的生命值，然后应用体质调整值。无论体质调整值是多少，你的角色初始永远至少会拥有1生命值。
	- 若是你给生命值投骰出 1 或 2（在应用任何体质调整值前），你可以进行重投。这是为了提升 1 级 PC 的生存能力。
6. 选择阵营
7. 记录初始装备：每个人有两天份的补给，50枚金币以及两根火把。每个职业还会获得一些初始装备
	1. 战士：链甲，盾牌，长剑
	2. 牧师：链甲，圣徽，硬头锤
	3. 法师：法术书，法杖，匕首，20枚金币
	4. 盗贼：皮甲，短剑，盗贼工具
8. 确定负重：
	- 大部分物品占一格，双手武器和中甲以上占两格，消耗品可以有限度堆叠，每100枚钱币占一格
	- 把物品分为已装备和在背包内的
	- 根据人物的力量属性，将两类物品依次从上往下填到人物卡中，然后查看最下方的物品落在哪个速率区间，即得到人物的移动速率
9. 标明护甲等级（AC）：基础AC由护甲决定，链甲为14，皮甲为12，无甲为10，有盾牌则AC+1。然后将敏捷调整值应用到AC。
10. 如果是魔法师，确定[[B2 边陲堡/边陲堡 参团指南#法师的初始法术\|初始法术]]。
11. 标明等级和XP：你的角色在游戏初始是 1 级，XP 为 0。
12.  给角色命名

### 法师的初始法术

法师的法术书内初始记录若干的1环法术：

| 智力  | 初始已知法术数 | 抄卷成功率 | 
| ----- | -------------- | ---------- |
| 3     | 1              | 20%        |
| 4–5   | 1              | 30%        |
| 6–7   | 2              | 35%        |
| 8–9   | 2              | 40%        |
| 10–12 | 3              | 50%        |
| 13–14 | 3              | 70%        |
| 15–16 | 4              | 75%        |
| 17    | 4              | 85%        |
| 18    | 5              | 90%        |

其中一个法术为[[OSE/法术与异能/经典奇幻/阅读魔法]]，其余1环法术自选，从[[OSE/职业/经典奇幻/魔法师]]的核心法表中选择。

## 如何游玩

打印角色卡，然后带上纸、笔和骰子即可。

游戏的基本流程就是我描述场景（荒野，地城，聚居地等等），玩家决定行动，然后我给出反馈，如此反复。不需要提前阅读规则，必要的时候我现场讲解。

因为是沙盒团，玩家可以做任何想做的事，剧情未来的发展连我也不知道。
