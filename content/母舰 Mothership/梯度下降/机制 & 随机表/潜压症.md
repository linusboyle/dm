监守发起潜压检定的有趣时机包括但不限于：当本回团开始时，乘组决定离开深渊时，乘员与其他人分开时，在深渊中任何地方恢复意识时，等等。

`dice: [[潜压症^table]]`

| dice: 1d100 | 潜压症                                                                                                                                                                                         |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1-9         | **强化同理心。** 每次见到 / 听到仿生人死亡时增加 1 压力。                                                                                                                                      |
| 10-14       | **记忆缺失。** 你无法想起关于你过去的某些细节。增加 `1d10` 潜压。                                                                                                                              | 
| 15-20       | **这是我家。** 24 小时内拒绝离开深渊。                                                                                                                                                         |
| 21-24       | **虚拟世界。** 你在做梦，处于昏迷中，磕嗨了或者被困在了软体世界里。这一切都不是真的，发生什么都无所谓。重启 / 醒来的最好方式就是开始打砸东西。`1d10` 轮内，不在打砸东西的每一轮都加深 1 潜压。 |
| 25-29       | **手足情深。** 其他深渊仿生人会将你视为它们中的一员。增加 `1d10` 潜压。                                                                                                                        |
| 30-34       | **模仿者。** 遭遇中现在有 50% 几率包含一名你的仿生人复制体。                                                                                                                                   |
| 35-39       | **罗科的怪蛇。** 如果你为君王（第 8 页）服务他就会将你的意识复制进一名仿生人体内并让你永生。立刻马上去做大脑扫描（第 5 页）然后听从它的命令。                                                  |
| 40-44       | **多疑的仿生人。** 其他人都是假货，它们在监视你。周围的乘员以 `[-]` 进行恐惧豁免。                                                                                                             |
| 45-49       | **失去 `1d5` 理智。** 你没法停止思考。君王会怎么做？把某个人掉包成炸弹人肉炸弹乘组里有人是炸弹是的但不是你某个人被掉包了阻止他们否则所有人都要死等他们看到假内脏他们就会懂了他们会懂的。       |
| 50-100      | **你真的是仿生人。** 你属于这里。你的角色现在由监守控制。                                                                                                                                      |
