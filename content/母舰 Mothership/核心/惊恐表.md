| 2          | **紧张：** 获得 1 压力。                                                                                       |
| 3          | **神经质：** 获得 1 压力，所有近距乘组获得 2 压力。                                                            |
| 4          | **不知所措：** 之后 `dice: 1d10` 分钟内所有投骰带有 [-]，压力下限提升 1。                                      |

| 6          | **受惊：** 获得一项新状态：恐惧症：在遭遇恐惧源时得要通过一次恐惧豁免 [-]，否则获得 `dice: 1d5` 压力。         |
| 7          | **梦魇：** 获得一项新状态：难以安睡，休息豁免带有 [-]。                                                        |
| 8          | **失去自信：** 获得一项新状态：选择一项技能，失去此技能的奖励。                                                |
| 9          | **泄气：** 获得一项新状态：只要有近距乘员豁免失败，获得 1 压力。                                               |
| 10         | **大难临头：** 获得一项新状态：感觉自己受到诅咒，厄运缠身。所有关键成功变成关键失败。                          |
| 11         | **多疑：** 之后一周内，每当有人加入你的团体（即使他们只离开了很短的时间），通过一次恐惧豁免，否则获得 1 压力。 |
| 12         | **作祟：** 获得一项新状态：有些东西开始会在晚上造访，包括梦中或视线边缘，很快对方就会开始提出要求。            |
| 13         | **作死：** 之后 24 小时里，只要遭遇陌生人或是已知敌人，你必须通过一次理智豁免，否则立刻发起攻击。              |
| 14         | **预知异象：** 角色立刻体验一次关于将临恐怖或是可怖事件的激烈幻觉/异象。压力下限提升 +2。                      |
| 15         | **紧张症：** `dice: 2d10` 分钟里变得毫无反应，呆若木鸡。减少 `dice: 1d10` 压力。                               |
| 16         | **狂暴：** 之后 `dice: 1d10` 小时内，所有伤害投骰带有 [+]。所有乘组获得 1 压力。                               |
| 17         | **沦陷：** 获得一项新状态：惊恐检定带有 [-]。                                                                  |
| 18         | **复合问题：** 按照此表投骰两次。压力下限提升 1。                                                              |
| 19         | **心脏病发/短路（仿生人）：** 损伤上限降低 1。`dice: 1d10` 小时内所有投骰带有 [-]。压力下限提升 1。            |
| 20         | **退场：** 投个新角色来参加游戏。                                                                              |
